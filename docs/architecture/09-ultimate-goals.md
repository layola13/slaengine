## 2. 不变项

- tag 后实现序不变：魔兽垂直贯通仍为第一程（repin → 导入族 → 资产桥 + ECS 骨架 → 战役首章 → 存读档/JASS → 联网双面 → 物理预测 → 录像/余面 → 通用广度，见 revised2/IMPACT.md §3）。
- 研究线与实现序分离：三款的逆向/参考研究线即刻并行（魔兽阶段二、CS 输入线、红警研究线），不占实现序。
- CS 与红警的实现侧支持工作在魔兽第一程贯通后按本篇位次展开；除非用户另行升格，任何线不得以终极目标为由抢占魔兽辖域的资源与汇报次序。
- 三款游戏对 slaengine 均为行为参考 + 支持目标：引擎实现保持自研 clean-room；外部源码（GPL、NOASSERTION 等）只学组织与行为，不取代码，此纪律与 04 的不变条款同源、对三款一致适用。

## 3. CS 支持的含义（细化候参考文档）

GoldSrc 的联网模型是预测-对账制（同一份移动代码在客户端先行推演、服务端权威纠正），与魔兽的 lockstep 帧同步是两种范式。终极目标要求两种范式在同一引擎内共存——这是本目标区别于「多做两款移植」的核心命题：引擎的模拟/网络抽象必须同时容纳确定性锁步与预测-对账。支持面清单（模块托管面、预测-对账联网环、资产格式面 BSP/MDL/SPR/WAD、与 lockstep 面的共存关系）由 CS 输入线在参考文档中逐项给出，本篇不预裁——该清单已由 10 号文《GoldSrc / CS 参考（网络与预测域）》给出（2026-11-08 入仓）。

## 4. 红警参考存档

- EA 官方 GPL 源码发布：红色警戒 1 与泰伯利亚黎明源码（2020 Remastered 合集仓；2025 年另有红警 1 原始恢复版独立仓）。更正（2026-11-08 红警线实测核查）：Tiberian Sun 与红警 2 的本体源码并未开源——electronicarts 组织全量清单无此仓，2025 发布批次为泰伯利亚黎明、红警、Renegade、Generals & Zero Hour；TS 相关官方开源只有任务编辑器（FinalSun / FinalAlert 2）。本节先前版本关于 TS 独立仓的记述有误，特此订正。
