# 06 编辑器（Blender）迭代环薄层设计

定案：**Blender 就是 slaengine 的编辑器**，不是备胎。内容制作
（建模、动画、场景装配）在 Blender 本体内完成；引擎侧不复刻
编辑器 UI，只补两样东西：**场景语义**与**边玩边改迭代环**。
本文件是这两样东西的薄层设计。

## 6.1 场景语义桥（已有资产，本节收束）

Blender 场景到引擎的语义通道已存在两段，不新建：

1. **sax3d 转换器**：Blender 场景 → SAX3D 声明（格式真理在
   SAX3D SPEC）；`crates/sax3d/` 内已有 `BLENDER.md` 与
   `CONVERTER_MAP.md`（材质映射表）为其成文面。
2. **slasl 的 Blender 节点面**：`crates/slasl/` 内已有
   `BLENDER_NODE_MATRIX.md` / `BLENDER_UBO_REVIEW.md`——材质
   节点语义到 shader 接口的对应在 shader 生产侧承载。

语义映射的汇合点仍是 PLAN C2/C6：SAX3D scene node 树 → ECS
实体 + ChildOf/Children 层级；node 的 transform/mesh/material/
skin/clip 引用 → 组件与句柄。本节的新增只有一条纪律：**语义
桥只传声明，不传行为**——Blender 侧的修改器、约束、驱动等求值
结果以烘焙后的声明（网格通道、clip 采样、变换矩阵）过桥，
求值器本身不进引擎；求值口径差异登记为转换器问题，不在引擎
侧补偿。

## 6.2 边玩边改迭代环（薄层本体）

目标形态：开发者在 Blender 里改场景/材质，运行中的引擎画面
随之更新，不重启 App。引擎侧薄层由三段构成：

| 段 | 形态 | 落点 |
|---|---|---|
| 变更感知 | 资产目录监视（源文件/转换产物的时间戳+内容戳）或 Blender 侧桥插件主动通知——机制选型见分叉 N2 | 宿主侧薄层（Zig 支持库或宿主脚本面，不进 ECS） |
| 重转换 | 变更资产经既有转换器重跑（sax3d 转换器 / slasl 编译），产物替换；转换失败**响亮报错且保留旧产物继续运行**（迭代环不许因一次坏保存杀掉会话，但也不许静默用旧产物冒充已更新——状态须在检查面可见） | 生产侧工具链的增量调用 |
| 热替换 | 新产物经 sla_asset 的重载路径换入运行中 World：句柄**世代递增**，旧世代句柄再访问响亮失败；引用该资产的实体经 C2/C3 重新生成或原位更新（按资产种类在实现期定） | sla_asset（重载路径为 C1 的增量面，P1 后段或 P3 视消费者） |

迭代环的延迟预算（保存→画面）本集只登记为**设计目标待实现期
实测**，不预填数字。

## 6.3 检查面（编辑器数据的引擎侧来源）

Blender 侧将来若需「选中实体看组件」类检查，数据一律来自
sla_ecs reflect 组的**描述符注册表**（03 M5）：类型名、字段
布局、显式 id——检查面是描述符的只读消费者，不要求引擎长
dyn Any 内省（PLAN §2.4 的长期替代形态在此兑现其用途）。
检查 UI 仍在 Blender 本体（面板/大纲视图），引擎侧只供数据
协议：描述符枚举 + 按 id 读字段摘要；协议格式随实现期与
Blender 桥插件（若 N2 选 B）一并成文。

## 6.4 明确不做

- 不做引擎内编辑器 UI（与 Blender 重复建设，定案禁止）。
- 不 fork Blender；桥插件（若立）是普通 Blender addon 形态，
  独立小件，不进引擎 workspace 成员表（它属编辑器侧资产）。
- 不把 Blender 文件格式（.blend）列为引擎运行时输入：引擎
  只消费 SAX3D 声明；.blend 是编辑器侧的源文件，与源码同级。
