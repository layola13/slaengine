## §1 对 VERDICT 八项裁断的逐项影响判定

总则：本修订不推翻任何一项裁断。判定分两档——**无冲突**（裁断
与新口径相容、无需动作）与**需复核**（裁断本体不动，但其外围
的实施模式/时机在实现期须经主会话确认一次，理由具名）。

| 项 | 裁断 | 判定 | 理由 |
|---|---|---|---|
| F1 sla_3d 内部形态 | (a) 单 crate + 域子目录 | 无冲突 | 双参考与里程碑序不触及 crate 拓扑；受影响的只是 sla_3d 内部域展开的先后（见 §4），那是排期不是裁断。两条重开触发不变 |
| F2 Zig f32 内核去向 | (a2) 支持库迁入、分阶段迁移（退出条件 = DEF-13/14 浮点关通过） | 无冲突 | 参考结构与魔兽目标不触及 math/geometry 内核的语言形态；总序只影响其迁入批次的排期（见 §4）。退出条件不被总序改写——关未过前仍不启动内核重写 |
| F3 sla_gpu 绑定 | (b) 自带 wasm 导入面 | 无冲突 | 绑定形态裁断与参考比重无关；位次影响见 §4（里程碑关键路径不经 sla_gpu） |
| F4 SAX3D 桥读实现 | (a) SLA 原生读实现（复刻面收薄 + Zig 校验器作进程外预言机生成 conformance 语料） | **需复核** | 裁断本体（SAX3D 侧）不动。复核点在其护栏模式向魔兽侧的**延伸问题**：F4 定形了「契约先行 + 进程外预言机生成一致性语料」的模式；魔兽导入族已有同形槽位（05 §5.4 conformance/），而双参考下 OpenRealm 的身份已升为并列参考——它在导入族语料里是只作「对照清单来源」（基稿口径），还是升为与 Zig 校验器同格的**行为预言机**（期望摘要的生成方之一），基稿与新口径之间没有定论。实现期开导入族语料前须确认一次。F4 自身的运行时校验范围子决定不受影响 |

## §5 架构含义：帧同步 → 确定性模拟契约

**含义链**（事实侧）：帧同步（锁步）的成立前提是各端模拟
逐回合一致，而一致只能来自确定性推进——定步进、同种子同
输入必得同结果。原版为此付出的机制代价在 S0/S11 已还原：
命令先同步后执行（输入是数据、不是即时动作）、自研查表 RNG
（种子开局同步、45 轮预热、随机状态折入每回合校验）、软件
浮点（不依赖硬件浮点语义）、三层校验和 + 失同步可信事件作
核查面。这说明帧同步**不是魔兽域的一个局部功能，而是对
引擎模拟核心的形态约束**。

**与物理座的同构**（互引）：物理座章程已独立地把同一约束写
成自己的底线——`crates/sla_physics/CHARTER.md` §6「定点确定性
是刚需：同一种子推演两次必须逐位一致……浮点非确定性正是
经典联机预测失配/失同步的根源」；§7 参照前提 1（确定性：同
状态同输入必得同结果）与前提 4（步进接受数据化的外力/控制
输入）；§4 步进器签名 `step(world, dt, inputs)`（inputs 为一等
数据、不藏回调）与锁步的回合推进（回合号 + 命令块 → 推进）
同形；§3/§5 的多未来预演与 will 生命周期（确认/修订/撤回）
正是联网客户端预测与权威对账的形态。**两处独立得出的同一
底线，在本修订里正式互引**：01 §1.3 确定性条 ↔ CHARTER §6/§7。

**定案后的状态**（边界须分清）：

- 21:13 定案使「联网正常运行 + 物理预测」成为最高优先目标
  本体，确定性由此在**魔兽引擎辖域内**（同步模拟 + 物理解算/
  预演）成为硬约束——已写入 01 §1.3，不再是候选。
- 未被本次定案决定的是**扩张问题**：确定性是否再升为覆盖全
  引擎（含通用域）的统一契约。其裁定时必须正面回答一个已
  登记的张力：ECS/goroutine 并行调度（01 §1.3 调度条）与确定性
  推进的执行序问题——物理座 §6 给出的调和形态（世界值式可
  多开 + 并行步进，每条分支内部仍确定）是现成的参照答案，
  但是否采为全引擎口径，候扩张裁定。
- 本稿不预裁扩张问题；扩张定案前，魔兽辖域外的实现不以确定
  性为验收门，魔兽辖域内的实现不得以「契约未扩张」为由豁免
  确定性。
